# 策略实验室 · 页面操作指南

> 面向「打开页面怎么用」。口径与 API 细节见 [`usage.md`](./usage.md)；
> 每条结论为什么长这样见 [`limitations.md`](./limitations.md)。
> 本页**全程零联网**（所有请求读本地 SQLite，不碰任何外部数据源）；
> **不接真实交易、不发下单指令**，只做历史研究与模拟。

## 0. 三分钟上手

1. 导航点「策略实验室」（`/lab`）。默认停在 **① 数据审计** —— 这个顺序是有意的：先看清能回答什么、不能回答什么，再动手填日期。
2. 切到 **② 实验与运行** →「新建实验」：起名 → 填 YYYYMMDD 起止 → 选观察期/组合 →（推荐）勾「用快照自带权重」→ 创建。**配置到此冻结**，创建后自动跑第一轮。
3. 进度条跑完（2 秒轮询，结束自动停）→ 切 **③ 信号与结果** 读三张表。
4. 想验证某个因子：**④ 因子消融** 选剔除因子 → 建消融实验 → **回 ② 点「运行」**（消融实验建完不自动跑）→ 回 ④ 选基线与消融对比。

## 1. 进入与前提

- 顶部两个 Tag 常驻：「只做历史研究与模拟」、「不接真实交易 · 不发下单指令」。
- 打开页面红条「后端未启动或尚未加载研究模块」→ 先起后端；**改过 `backend/` 后需重启**才生效（前端改动不用）。
- 整页零联网：审计、建实验、跑分、看结果全部读本地库，不会触发任何采集或外发。

## 2. ① 数据审计（先看这个）

| 区块 | 内容 |
|---|---|
| 「做不了」红标清单 | 来自 `GET /api/research/capabilities`。前端表单的可选项也读它，不在前端写死 |
| 五域数据审计表 | 每域 `READY`（绿）/ `PARTIAL`（橙）/ `BLOCKED`（红）+ 说明 |
| 逐信号日可回测性 | 每个信号日的状态与原因；空库时显示「库里还没有信号日快照」 |
| 审计结论 | 底部蓝条汇总 |

**看懂状态再建实验**：`BLOCKED` 的域不是 bug，是本库数据边界（日线未回填、沪深300 不落库、无历史股票池），详情见 limitations.md。

## 3. ② 实验与运行

### 新建实验表单

| 字段 | 默认 | 说明 |
|---|---|---|
| 实验名 | 必填 | 例：六维前5 · 默认权重 |
| 起始日 / 结束日 | 必填 | `YYYYMMDD`，例 `20261006` |
| 观察期 | `T+1/3/5`（审计给什么就默认什么） | 只能取 T+1/3/5/10/20；**多选 = 多重比较更重**，别贪多 |
| 组合规则 | `top5` | top5 / top10 / top30 多选 |
| 前 N 名 | 10 | 研究层排名取前多少名 |
| 最低分 | 0 | 低于此分不入选 |
| 权重 | 勾「用快照自带权重」 | **推荐勾选**：按快照入库时自己的权重重放 = 复现当初口径。不勾则六键全填，**缺一个键 = 那个因子被静默消融** |
| 交易成本 | 不勾 | 勾了按研究假设扣费（佣金万 2.5 + 5 元下限 / 卖出印花税千 0.5 / 滑点 0.1% / 名义 10 万），弹黄条提醒，运行 warnings 里再提醒一次 |

### 运行

- **创建后自动开跑第一轮**；列表里也可再点「运行」。
- 「查看」会**直接跳到 ③ 信号与结果**并预选该实验。
- 重复点启动弹 409「无法启动」—— 同一把锁里拒绝，**不会静默开出第二条并行任务**。
- 运行卡：进度条 + 阶段（stage）+ warnings 黄条 + error 红条。2 秒轮询，**结束即停**，不后台空转；进度写库，进程重启不丢。
- **取消是协作式**：已写入的信号保留、指标不写 —— 半成品不冒充完整结果。
- **删除**：列表操作列红色「删除」→ 二次确认框 → 连同该实验的**全部运行、信号、逐条结果、汇总指标一次删净**（别的实验一行不动，不可恢复）。还有未完成的运行时后端 409 拒绝并要求先取消，弹窗会把理由原样带回。
- 实验列表的股票池列：`A·当前`（蓝）= 当前股票池回看（带幸存者偏差，页面与文档都重申）；`B·禁用`（红）= 历史股票池模式，**后端显式拒绝**，因为本库没有「当时真实存在的完整名单」。
- 配置哈希列显示前 8 位，悬停看全 —— 配置一改就是另一个实验。

## 4. ③ 信号与结果

顶部选实验 + 观察期筛选，下面三张表：

### 汇总指标（组合 × 观察期）

- **样本 < 30 显示黄色**：均值不稳，不要只看均值。
- 「未到期 / 缺数据」两列**分开记账** —— 「还没到时候」和「判不了」是两回事。
- 理论均值 / 中位数 / 有效成交 / 买不进率 / 交易成本逐列给；**最大回撤恒为 `-`**：没有逐日组合净值曲线，拿个股收益排开算回撤是假的（夏普等同理不做）。

### 信号

- 快照分 vs 重放分对拍，容差 0.06。
- **重放排名 ≠ 快照排名**时带 `≠` 标记：快照本身没有并列裁决，引擎按 code 升序固定裁决 —— 已知且有意的差异，不是 bug。

### 逐条结果

- 状态三档：`OK`（进统计）/ `PENDING`（观察期没走完）/ `NO_DATA`（缺行情判不了）。
- **复权口径三档 Tag**（含义与引擎同一份定义）：
  - 绿「已折算」= 两端 `adj_factor` 都有且不同，收益按折算后可比价算；
  - 蓝「无除权·直算」= 两端因子相同，确认这段没除权，不复权价直算本就对；
  - 橙「判不了」= 缺因子 —— 若期间发生过除权，该收益不反映真实回报。
  - 没算出收益的行显示 `-`（谈不上口径），**不填某个值冒充**。
- 理论收益 / 超额收益 / 可执行收益**三列并排不合并**；超额收益恒 `-`（指数不落库，不拿当前点位冒充历史值）；可执行收益默认不配成本则一律 `-`。
- 买入 / 卖出列是模拟成交判定（`FILLED` / `UNFILLABLE` 一字涨停买不进 / `LIMIT_DOWN` / `UNCONFIRMED` / `NOT_DUE`），不是真实成交。
- 行数 = 信号数 × 观察期数，超上限截断时顶部黄条提示 —— **用观察期筛选缩小范围**，所有截断都如实标出、不静默丢数据。

## 5. ④ 因子消融

1. 选要剔除的因子（多选），提示行会写明「其权重归零、其余不变」—— **归零不是删键**，删掉会从回退路径重新计入。
2. 「新建消融实验」→ 表单会带黄条列出将剔除的因子 → 创建。
3. **建完不自动跑**：建完留在本页（对比下拉自动选中消融侧），回 ② 找到它点「运行」。
4. 回 ④ 顶部「对比：基线 vs 消融」选两个实验：只对比**同组合、同观察期**的行（对不上号的直接不进表）；基线和消融选了同一个实验会弹黄条「对比没有意义」。
5. 对比表在选中实验时**读一次**；刚跑完的新结果要重选一次（或刷新页面）才会刷新。

**结论边界**：消融只回答「换这套权重后，排名与收益怎么变」，**不宣称该因子的边际贡献** —— 快照只存每个维度的百分位和权重，不存因子原始值。

## 6. 常见情况速查

| 现象 | 原因 / 怎么办 |
|---|---|
| 打开页面红条「后端未启动或尚未加载研究模块」 | 起后端；改过 `backend/` 要重启 |
| 复权口径一排橙色「判不了」 | `daily_bar` 未回填、`adj_factor` 缺 —— 当前内网常态，数值算得出但别当真实回报 |
| 超额收益全是 `-` | `index_daily` 空，无基准，如实留空 |
| 最大回撤 / 夏普恒 `-` | 没建逐日净值曲线，不产这两个数 |
| 点「运行」弹 409 | 已有未完成运行，等它结束或先取消 |
| 点「删除」弹「无法删除」 | 同上：还有未完成的运行（或取消后线程还没退干净）—— 等它结束 / 先取消，稍候再删 |
| 逐条结果「已截断」 | 行数 = 信号 × 观察期，用观察期筛选缩小 |
| 结果表数字没更新 | 表是选中实验时读一次的，重选一次或刷新页面 |
| 还没有任何信号日 | 先跑每日采集产出 `main_force` 快照，审计页会显示「库里还没有信号日快照」 |
