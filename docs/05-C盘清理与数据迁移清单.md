## 四、目录规划（已定，**未执行**）

按你的选择：**两类分开**，记忆和可重建缓存绝不混放。

```
D:\dev-cache\            ← 可重建的下载缓存（删了也无所谓）
├── npm\                  ← A2  npm-cache  3.30 GB
└── yarn\                 ← A1  Yarn       6.85 GB

D:\opencode-data\         ← 会话记忆（绝不能误删）
└── opencode.db           ← B8  42 MB
```

**为什么不合并**：`dev-cache` 整个目录将来可以无脑删，而 `opencode-data`
里是你的会话历史，删了就没了。放一起会丧失「哪个能删」的判断依据。

## 五、执行命令（**均未执行**，等你逐项点头）

### A1 · Yarn 缓存 → D 盘（6.85 GB）

```powershell
New-Item -ItemType Directory -Force D:\dev-cache\yarn | Out-Null
yarn config set cache-folder D:\dev-cache\yarn
# 确认新路径生效后再删旧的：
yarn cache dir      # 应输出 D:\dev-cache\yarn
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Yarn"
```

### A2 · npm 缓存 → D 盘（3.30 GB）

```powershell
New-Item -ItemType Directory -Force D:\dev-cache\npm | Out-Null
npm config set cache D:\dev-cache\npm
npm config get cache                       # 应输出 D:\dev-cache\npm
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\npm-cache"
```

### A3 · pnpm 旧残留直接删（1.74 GB，store 已在 D 盘）

```powershell
pnpm store path       # 复核：应为 D:\.pnpm-store\v3
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\pnpm-cache"
```

### A4~A9 · 一批可重建缓存直接删（约 3.6 GB）

```powershell
Remove-Item -Recurse -Force "$env:USERPROFILE\.gradle"
Remove-Item -Recurse -Force "$env:APPDATA\npm-cache"
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Cypress"
Remove-Item -Recurse -Force "$env:USERPROFILE\.bun"
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\CrashDumps"
```

### B8 · OpenCode 会话记忆 → D 盘（42 MB，**要你手动做，会断会话**）

```powershell
# 1) 备份（必做 —— 这是你的会话历史）
Copy-Item "$env:USERPROFILE\.local\share\opencode\opencode.db" `
          "$env:USERPROFILE\.local\share\opencode\opencode.db.bak" -Force

# 2) 完全退出 OpenCode（TUI + 桌面版），确认没有 opencode 进程
tasklist | findstr /i opencode

# 3) 移动（db + wal/shm 三个一起，缺一个都会丢数据）
New-Item -ItemType Directory -Force D:\opencode-data | Out-Null
$src = "$env:USERPROFILE\.local\share\opencode"
Move-Item "$src\opencode.db"    D:\opencode-data\
Move-Item "$src\opencode.db-wal" D:\opencode-data\ -ErrorAction SilentlyContinue
Move-Item "$src\opencode.db-shm" D:\opencode-data\ -ErrorAction SilentlyContinue

# 4) 设环境变量（用户级，永久生效）
setx OPENCODE_DB "D:\opencode-data\opencode.db"

# 5) 重启 OpenCode，验证会话历史还在
opencode service stop
opencode service start
```

> ⚠️ **第 2 步会掐断我们当前的会话**，所以这步只能你退出后自己跑。
> 跑之前先把 `docs/04-backlog.md` 和港股这次的改动看一眼（都已落盘在 D 盘）。
> 若回滚：把三个文件移回原位、`reg delete` 掉 `OPENCODE_DB` 即可。

### B1 · WSL Ubuntu → D 盘（23.21 GB，**最大单项**）

```powershell
wsl -l -v                      # 先看发行版名字与状态
# 导出（保数据，可能要几分钟）
wsl --export Ubuntu D:\wsl-ubuntu.tar
# 注销原位置
wsl --unregister Ubuntu
# 导入到 D 盘（--version 2 保持 WSL2）
wsl --import Ubuntu D:\wsl-ubuntu D:\wsl-ubuntu.tar --version 2
# 验证能启动后再删掉 D:\wsl-ubuntu.tar
```

> ⚠️ **动之前必须先 `wsl` 进去确认里面没有你要的东西** —— 23 GB 不像是空系统。
> 这一项收益最大，但也是唯一可能「删错就回不来」的，**没有你的确认我不会做**。

### B2 · 微信（15.21 GB，**我不碰**）

微信 4.0 里「设置 → 存储空间」可清理缓存/聊天文件；要搬家就在同一处改
存储位置到 D 盘。**聊天记录属于不可再生数据，任何脚本都不该碰它。**
